Deep Forest Academy: углублённое изучение математики.

## Запуск

```bash
npm install
npm run dev
```

Откройте **http://localhost:5173**. Если порт занят, остановите старый `npm run dev` (Ctrl+C в том терминале) и запустите снова — адрес не должен меняться.

Сборка:

```bash
npm run build
npm run preview
```

## Как устроена программа

1. Регистрация: имя, которое попадёт на диплом.
2. Вкладка **Программы** — сейчас открыта «Математика»; остальные факультеты помечены как будущие.
3. Школьные курсы открываются последовательно. Последний из них — «Язык математики и доказательства».
4. После школы параллельно: линейная алгебра, **математический анализ I**, аналитическая геометрия и дискретная математика. Алгебра групп, колец и полей открывается после линейной алгебры. Теория чисел — после дискретной математики.
5. Анализ II–IV идут последовательно. В анализе IV отдельным блоком стоит мера и интеграл Лебега; после него открывается функциональный анализ. Дифференциальные уравнения открываются после анализа I. Комплексный анализ и строгая теория вероятностей — после анализа II. Топология — после анализа I.
6. За занятие — оценка **0.0–4.0**. В журнал пишется лучшая попытка. Средний балл (GPA) — среднее.
7. **Диплом** выдаётся за школьную программу и **базовый курс**: анализ I, линейная алгебра, алгебра, аналитическая геометрия, дискретная математика (без анализа II–IV, топологии и остальных предметов углублённого курса). Средний балл на дипломе — среднее по занятиям базового курса.
8. **Диплом лауреата** — если сданы все курсы программы. Средний балл считается по всем занятиям; при высоком среднем добавляется латинская степень (cum laude / magna / summa).

Материалы уроков опираются на стандартные учебники (Алимов, Мордкович, Атанасян, Фихтенгольц, Ильин–Позняк, Гнеденко, Виноградов, Александров и др.); источники указаны в каждом занятии.
